# Avaliações com 5 pessoas

## Formulário

As respostas são coletadas por este Google Form, com os mesmos campos de [`template-avaliacao.md`](template-avaliacao.md) (nome, data, perfil testado, o que funcionou, o que não funcionou, captura de tela do erro, funcionalidade não testada, sugestões):

**<https://docs.google.com/forms/d/e/1FAIpQLScXCqFxWw11nxlUGAPa7bIfCCOnAGMKg5rnnSjKtZ1_30yayw/viewform>**

`template-avaliacao.md` continua no repositório como registro de quais campos o formulário cobre (e como alternativa offline, caso algum avaliador prefira preencher em Markdown em vez do Forms).

## Processo

1. Envie o link do repositório (`git clone`) e o [`README.md`](../../README.md) (instalação) + [`MANUAL_DE_USO.md`](../../MANUAL_DE_USO.md) (como usar), junto com o link do formulário acima, para 5 colegas de curso ou profissionais da área.
2. Peça para cada um instalar localmente, testar os fluxos dos 3 perfis (ou pelo menos um) e responder ao formulário.
3. Acompanhe as respostas na planilha do Google Sheets vinculada ao formulário (aba "Respostas" → ícone do Sheets).
4. Quando as 5 respostas estiverem coletadas, exporte o PDF consolidado: no formulário, aba "Respostas" → menu **⋮** → "Imprimir todas as respostas" (ou exporte a planilha vinculada como PDF). Salve o arquivo final nesta pasta (ex.: `avaliacoes-consolidadas.pdf`) — é esse PDF que o PDF do PI II pede como entrega da Situação 3.
5. Para cada problema relatado que fizer sentido corrigir, registre a correção (ou a justificativa de não aplicar) — ver "Registro de correções" abaixo.

## Registro de correções

Depois de coletar o feedback, adicione aqui (ou num arquivo `correcoes.md` nesta pasta) uma lista: problema relatado → o que foi feito → commit/change correspondente. Itens não corrigidos precisam de uma justificativa curta (ex.: fora do escopo acadêmico, já documentado como Non-Goal).
