# Avaliações com 5 pessoas

## Processo

1. Envie o link do repositório (`git clone`) e o [`README.md`](../../README.md) (instalação) + [`MANUAL_DE_USO.md`](../../MANUAL_DE_USO.md) (como usar) para 5 colegas de curso ou profissionais da área.
2. Peça para cada um instalar localmente, testar os fluxos dos 3 perfis (ou pelo menos um) e preencher uma cópia de [`template-avaliacao.md`](template-avaliacao.md).
3. Colete as 5 respostas de volta (Markdown, PDF, ou até só por mensagem) e salve cada uma nesta pasta como `avaliacao-<nome>.md` (ou `.pdf`).
4. Depois de coletadas, gere um único PDF consolidando as 5 (ex.: `pandoc avaliacao-*.md -o avaliacoes-consolidadas.pdf`, ou copiar tudo para um documento e exportar como PDF) — é esse PDF consolidado que o PDF do PI II pede como entrega da Situação 3.
5. Para cada problema relatado que fizer sentido corrigir, registre a correção (ou a justificativa de não aplicar) — ver "Registro de correções" abaixo.

## Registro de correções

Depois de coletar o feedback, adicione aqui (ou num arquivo `correcoes.md` nesta pasta) uma lista: problema relatado → o que foi feito → commit/change correspondente. Itens não corrigidos precisam de uma justificativa curta (ex.: fora do escopo acadêmico, já documentado como Non-Goal).
